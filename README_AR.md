# الحرية المالية - مشروع Android الصحيح

ارفع **محتويات هذا المجلد** إلى جذر مستودع GitHub، وليس المجلد نفسه وليس ملف ZIP.

يجب أن تظهر في الصفحة الرئيسية للمستودع هذه العناصر مباشرة:
- package.json
- capacitor.config.json
- مجلد www وفيه index.html
- مجلد .github/workflows وفيه android.yml

بعد Commit افتح Actions وشغّل Build Financial Freedom APK. بعد نجاح البناء نزّل Artifact باسم Financial-Freedom-APK وفك ضغطه ثم ثبّت app-debug.apk.
